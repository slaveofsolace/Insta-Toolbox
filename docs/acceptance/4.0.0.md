## Tampermonkey regression gate

Mac testing of the `9e9bcb6` candidate reported repeated history scrolling with
no group-chat removal, an incomplete two-reel run, and no visible error. That
candidate has **not passed authenticated Unsend acceptance**. Desktop and PWA
expansion are deferred while the userscript is repaired.

Three source regressions were reproduced against 3.1.12: vertical column
alignment was treated as incoming-message alignment, empty hidden spacers
prevented reaching outgoing wrappers, and identical media previews prevented
verification after a real ID-less row removal. Narrow corrections retain
received-message checks, unchanged-neighbor evidence and stable postconditions.
The userscript also retains error/stopped summaries without requiring a prior
diagnostic scan. `tests/dm-group-reel-regression.test.js` covers the reproduced
cases; source fixes do not establish compatibility with the failing Mac page.

Release still requires generated-userscript primary-flow tests and a successful
Mac rerun. No stable update is promoted from this development record.

The generated-userscript primary-flow regression gate now passes six cases:
Standard and Fast each remove two ID-less reels in direct and group-style
layouts, preserve the received reel, and activate each native control exactly
once. Two uncertain-outcome cases retain the messages, show the error without a
preliminary scan, and never retry the dispatched action. This run also exposed
and fixed a message-container selection error after DOM shrinkage: semantic
message rows now outrank surrounding header/card child counts.

The full unit suite passes **565/565** after these corrections. New-tab checker
drafts are isolated with the existing Tampermonkey tab APIs; same-tab reload
retains that tab's draft. Legacy shared captures are neither imported nor
deleted. Expected counts, page counts and partial-result reasons now survive
reload and appear in reports. Missing server records remain unverified; this

## Userscript spacing and labels

The userscript uses 8px label-to-control gaps and 16px field separation, with
44px controls retained. Message choices use plain labels. Unavailable reaction,
managed-tab and notification options remain disabled; shorter copy does not
change their implementation status. Dark disclosure text is explicitly themed,
including its text-fill color and forced-colors fallback.

The UI patch passes 568 unit tests, the six generated-userscript media cases,
and 18 rendered field/settings states across light/dark themes, 320px width,
short windows, true 200% zoom, reduced motion and forced colors. The existing
six responsive and two confirmation-layout cases also pass. Screenshots were
reviewed after a dark disclosure-text defect was corrected. These are local
Chromium fixture checks, not authenticated Instagram or human screen-reader
acceptance. No desktop/PWA redesign is included in this patch.

## Implemented changes

- Abortable waits release listeners, observers, and timers on every settlement
  path, including registration races and throttled deadlines.
- Both message-removal paths reject contradictory ownership and require settled
  removal evidence. Changed preview text alone is not a successful Unsend.
- Freeze and page exit revoke active message authority. A dispatched action is
  recorded only when removal is proven; otherwise its outcome remains uncertain.
  Returning to the page does not replay the plan. Ordinary focus changes do not
  revoke a run.
- Settings use additive defaults and shared validation. Layout reset and
  appearance reset have separate effects. Theme, density, blur, and opacity retain
  their saved values, and per-run review choices remain independent of defaults.
- Inbox coordination, read-only discovery, tab-pool ownership, and metadata
  runtime modules have deterministic tests. They are not connected to live inbox
  execution.

   [Inbox cleanup](../INBOX_CLEANUP_4.0.md). Neither is an enabled product feature.

   mutation acceptance. Fixture success is not authenticated compatibility.
6. Pass exact-commit CI, Windows install/uninstall lifecycle, and macOS packaging
   before release promotion. Local version alignment, generation, Chrome pairing,
   archives, and checksums have passed. Do not replace the stable update artifact
   with this unfinished development build.

No real inbox-wide cleanup is a development test. Browser closure, discarded
pages, expired sessions, computer sleep, and restart do not retain authority.

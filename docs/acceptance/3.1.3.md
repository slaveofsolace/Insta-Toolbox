## Scope

This patch replaces repeated full-list reconciliation with one Instagram-shaped
cursor traversal. It adds current follow-list request parameters, explicit
platform-limit and missing-cursor outcomes, and matching progress text. Partial
rows remain visible and downloadable but cannot drive account actions. Follow /
Unfollow, DM Unsend, storage, migrations, pairing, and action-confirmation
contracts are unchanged.

## Nonclaims

The browser-control runtime was unavailable during source research, so no
authenticated Instagram response was captured in this worktree. Account-free
fixtures do not prove current authenticated compatibility, human screen-reader
use, Windows publisher trust, or Apple notarization. This patch performs no
Instagram account mutation.

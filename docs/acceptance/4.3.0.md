# 4.3.0 acceptance

## Automated scope

The local source gate passes 1,095 tests, including release-alignment checks.
The generated userscript Ghost fixture processes twelve synthetic conversations
in groups of ten and two, closes the first group before opening the second,
verifies each removal and preserves received messages. It uses real Chromium
windows and Web Locks with fixture page data and a userscript-manager adapter.

The release candidate must pass exact-commit CI: the complete browser fixtures,
Chrome pairing, 45 overlay states, 11 PWA states, Windows and macOS package
lifecycle, dependency audit, archive checks and checksums. No visual tolerance
is widened. Release promotion accepts only a successful current-main run.

The inbox review regression constrains native search/select widths inside grid
fields, including narrow panels and actual 200% Chromium zoom.
The lockfile removes the vulnerable HTTP cache dependency and preserves patched
Undici resolution.

## Native evidence and nonclaims

A newest-one Unsend passed on the earlier installed `451a9f2` candidate.
Its reaction pass stopped before removal. That is historical evidence, not proof
of native 4.3.0 reaction compatibility. See [4.2.1 acceptance](4.2.1.md).

Current ten-tab authenticated execution, corrected native reaction removal,
growth follow/unfollow transitions and human screen-reader use remain unverified.
Fixtures do not establish whole-inbox discovery, Firefox/Safari compatibility,
operation after browser shutdown or complete erasure of saved copies.

No live Instagram mutation is performed by the source, CI or package checks.
Only verified removals increment the result; unresolved outcomes stay visible.

# 4.0.1 development acceptance

This is an unreleased source checkpoint, not a stable release. Package metadata
remains 4.0.0 while integration continues. The published 3.1.12 update channel
has not changed.

## Restored Unsend

- Removed Fast from the runner, reservations, preferences, and both in-page UIs.
- Restored visible-first whole-conversation traversal, bounded hover/menu waits,
  pre-dispatch removal observers, and adaptive 1–2 second pacing.
- Retained finite Newest/Oldest ordering, received-message protection, verified
  removal accounting, and Stop settlement without retrying uncertain actions.
- Generated-userscript reply and story fixtures each remove the intended newest
  message once, retain received messages, and report one verified removal.
- Direct and group reel fixtures remove both sent reels. An uncertain fixture
  reports uncertainty without retrying. These are synthetic layouts, not live
  account results or a throughput benchmark.

## Inbox cleanup

The userscript includes native discovery, exact-ID selection, confirmation,
serial same-tab execution, Pause, Skip, Stop, and bounded local job history.
The confirmation discloses that messages sent during execution may also be
removed. Discovery may mark conversations read and does not claim full inbox
coverage without terminal proof.

Navigation requires an exact route and a proven replacement message pane;
changing the URL alone is insufficient. Reused or unproven empty panes stop
before Unsend. This native compatibility gate remains open.

Behavioral fixtures cover cancellation, two selected conversations, account
changes, stale confirmation, busy account locks, interrupted storage, retained
verified counts, and reload without restored authority. Rendered userscript
checks cover dark/light, narrow, short-window, and real 200% zoom layouts with
44px controls and one live region. Screenshots contain synthetic content only.

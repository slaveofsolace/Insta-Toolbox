## Inbox cleanup

The userscript includes native discovery, exact-ID selection, confirmation,
serial same-tab execution, Pause, reviewed Resume, Skip, Stop, and bounded local job history.
Ghost mode defaults to **All available** and scans the exact Primary, General,
or Requests sections Instagram exposes in the current inbox. It does not invent
missing sections or claim whole-history coverage without terminal proof.
The confirmation discloses that messages sent during execution may also be
removed. Discovery may mark conversations read and does not claim full inbox
coverage without terminal proof.

Navigation requires an exact route and a proven replacement message pane;
changing the URL alone is insufficient. Reused or unproven empty panes stop
before Unsend. This native compatibility gate remains open.

Behavioral fixtures cover cancellation, two selected conversations, account
changes, stale confirmation, busy account locks, interrupted storage, retained
verified counts, and reload without restored authority. Rendered userscript
checks cover dark/light, narrow, short-window, and real 200% zoom layouts with
44px controls and one live region. Screenshots contain synthetic content only.

Native header labels and a name/handle filter are connected to the review list.
Three rendered behavioral gates cover discovery labels, plain versus verified
handle matching, preserved hidden selections, and exact Review/Cancel without
removals. Five populated-list layout states cover the same viewport matrix.
An additional generated-userscript flow selects two synthetic chats, accepts the
exact confirmation and uses the production controller plus shared DM runner.
It removes one own message per selected chat in order, preserves four received
messages, leaves an unselected chat unchanged and stores no action authority.

## Own-reaction cleanup

The userscript can optionally run a second bounded pass after a completed
Unsend run. It removes only a reaction whose native details row proves it
belongs to the verified signed-in account. Message authorship, right alignment,
or a matching emoji alone are not ownership proof.

Generated-browser acceptance opens the production confirmation, proves Cancel
removes nothing, then removes one exact owned reaction from a received message.
The received message remains, the badge disappears, the native dialog closes,
and the summary records one verified reaction removal. Extension, desktop, and
PWA reaction execution remain unavailable. Current authenticated Instagram
compatibility still needs a specifically approved disposable reaction.

## Presence

Presence is a compact userscript session rather than a plan builder. It exposes
five choices: view stories, react to stories, like posts, follow people, and
accept follow requests. The only other choice is a finite maximum from 1 to 50.
Manual Follow / Unfollow remains available in one secondary disclosure.

Start opens one review naming the signed-in account, enabled actions, and
maximum. Accepted authority exists only in memory, expires within 15 minutes,
and is bound to that account and exact choice set. Pause prevents the next
action, Stop aborts the wait before another action, and an uncertain result
halts the session without retrying it.

Presence and Ghost now hold the same account-scoped Web Lock for their full
reviewed sessions. An occupied lane rejects the second mode before it can click,
and the lane is released only after the active operation settles. Their reviews
remain separate and cannot authorize each other.

The native adapter re-resolves visible posts, profiles, requests, and stories
immediately before one click and requires a matching postcondition. Story
reactions include opening the story first. Seven focused controller tests and
eight generated-userscript browser gates cover runtime-only review authority,
Pause/Resume/Stop, exact target changes, confirmation-before-click, post likes,
follows, request acceptance, story opening/reaction, cancellation, and five
responsive states including true 200% zoom. These are deterministic fixtures,
not current authenticated Instagram compatibility.

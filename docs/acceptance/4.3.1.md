# 4.3.1 acceptance

## Regression

Worker startup previously required the original thread URL and launch fragment.
Instagram can restore the inbox in a new tab, leaving that worker unattached.
The earlier browser fixture opened the assigned thread itself and restored its
fragment, hiding this failure.

The userscript now captures launch correlation at document start, keeps it in
userscript-manager tab storage, and validates it against the active private job.
A redirected worker finds its exact assigned thread using native inbox rows.
Targeted discovery stops when that thread is mounted; it does not rescan the
whole inbox before cleanup. Account, job, thread and runner readiness are checked
again before starting Unsend. Navigation failures retain their exact cause.

## Automated scope

The source suite passes 1,102 tests and covers inbox redirects, invalid saved launch correlation,
Stop during navigation, failed navigation, batch closure and pending mutations.
Delayed layout callbacks no longer become navigation timeouts. Cancellation and
approval expiry still prevent the first native click, including after a delayed
timer. Layout observers and abort listeners are released on every settlement.
The generated-userscript browser fixture redirects every worker to the inbox
and clears its fragment, including full-page redirects that retain manager-tab
storage. Production code alone opens the assigned conversations.
The redirect occurs after early correlation capture, matching document-start
injection rather than racing an external fixture script download.
The fixture returns a newly opened tab handle immediately, matching
`GM_openInTab`; a startup redirect is not mistaken for failed tab creation.
It processes twelve synthetic chats in ten-then-two groups, verifies one sent
message removal per chat, and preserves received messages.

Release gates include full browser fixtures, Chrome pairing, 45 overlay states,
11 PWA states, dependency audit, archive verification and Windows/macOS package
lifecycle. Existing screenshot images and tolerances remain unchanged. Electron
44.5.1 is compared against those images; original capture provenance is retained.
Archive verification uses the named exports from `@electron/asar` 4.3.1.

## Native evidence and limits

Read-only inspection of the current Chrome inbox found native conversation
buttons without thread links. No real inbox cleanup was performed for this
patch. Fixture success does not prove authenticated batch removals, reaction
cleanup, complete inbox discovery or human screen-reader acceptance.

Mutual Checker partial comparisons remain reviewable and downloadable. Missing
matches are unknown, not confirmed non-mutuals. Virtualized captures accumulate
unique accounts across mounted windows; Instagram may still omit records.

The manager and worker tabs must stay loaded. Unknown removal outcomes remain
separate from verified removals. A stopped, expired or replaced launch cannot
resume action authority. Release promotion uses exact successful main artifacts.

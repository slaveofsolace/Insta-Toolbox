# 4.1.2 acceptance

This record separates source tests, generated-browser fixtures, and current
authenticated Instagram behavior. The stable Tampermonkey channel changes only
when the release is published.

## DM Unsend retained-slot verification

- Instagram may keep the outer virtual-list slot after a confirmed Unsend while
  removing the exact native message group inside it.
- Success requires the exact clicked group to detach, exactly one matching
  payload to disappear, the same message window to remain anchored, and one
  adjacent exact native message to remain when the window contains neighbors.
- Duplicate-text messages are counted rather than treated as unique. A matching
  payload that remounts during settlement keeps the outcome uncertain.
- Random nested-group unmounts, edited content, loading states, optimistic
  changes that revert, changed threads, open dialogs, and ambiguous ownership
  remain rejected.
- Ghost uses the same runner, exact-thread authorization, account lane,
  checkpoint, and uncertain-outcome stop.

## Presence controls

- Current Instagram story-tray tiles exposed as `role="button"` are discovered
  by their exact accessible story label.
- Current post actions exposed as role buttons with a descendant accessible
  label are included in exact action matching.
- Execution revalidates the reviewed connected control and verifies the story
  viewer or resulting action state before recording success.
- Legacy profile-first story navigation remains as a fallback. Fabricated
  routes, coordinate clicks, restriction bypasses, and ambiguous controls are
  not used.

## Authenticated gates

- Install the exact candidate userscript in the intended persistent profile.
- Unsend one disposable sent message, then continue across multiple disposable
  messages without a false uncertain stop.
- Open one available story through the exact visible story-tray control.
- Recheck restriction, changed-account, changed-thread, Stop, and inactive-tab
  behavior separately.
- Any Like, Follow, reaction, or Unsend mutation requires its exact action-time
  authorization and verified result.

No authenticated mutation is claimed until it is recorded separately. Current
Instagram markup can change independently of fixture coverage.

# 4.1.1 acceptance

This record separates source tests, generated-userscript browser fixtures, and
authenticated Instagram acceptance. The stable Tampermonkey channel changes
only when the release is published.

## DM Unsend continuation

- One pre-armed postcondition receives a full ten-second settlement window and
  must remain true for 350 milliseconds. A slow native update no longer spends
  the stability budget before verification begins.
- Stop still prevents another mutation while the exact dispatched action is
  allowed to settle. Only a verified removal changes the count or ledger.
- Keyed removals accept native bottom anchoring after the message list shrinks.
- If Instagram replaces the virtual message container, success requires the
  exact target key to be absent and at least two unchanged keyed neighbor
  anchors to prove the same window. Missing anchors remain uncertain.
- Wrong conversations, restrictions, open confirmation dialogs, loading
  states, changed ownership, recycled rows, optimistic reversions, and
  unproven outcomes still stop the run.
- Ghost uses the same verified runner and retains its durable dispatch marker,
  account lane, checkpoint, and uncertainty handling.

The deterministic DM and Ghost fixtures cover delayed removals, Stop during a
delayed settlement, native bottom anchoring, exact scroller replacement,
virtualized history, direct and group chats, replies, media, unavailable-account
labels, received-message protection, and true uncertain outcomes.

## Presence navigation

Presence no longer activates a discovered `/stories/` link directly. It binds
the story hint to one exact visible profile control, opens and verifies that
profile, rechecks account and restriction state, resolves one visible story
control, and verifies media and controls inside one story viewer. Unrelated
page media cannot prove success. Missing or ambiguous controls are skipped
instead of guessed.

Fixtures cover profile-first story opening, delayed Home rendering, stale page
media, restriction surfaces, account changes between the two clicks, and the
profile → story → reaction order. No coordinate clicks, fabricated routes, or
restriction bypasses are used.

## Automated evidence

- The complete repository suite passes 999/999 tests.
- Generated userscript and extension artifacts must reproduce from source.
- The complete repository suite, extension/userscript acceptance, Chrome
  pairing, browser QA, overlay and PWA visual checks, package lanes, dependency
  audit, repository hygiene, checksums, and publication scan must pass at the
  exact promoted commit.
- Automated fixtures do not change Instagram account data.

## Authenticated gates

- Run Unsend on disposable sent messages until stable exhaustion and confirm no
  false uncertain stop after a delayed native update or list remount.
- Verify Stop after dispatch settles only that action and never begins another.
- Open one available story through the exact profile-first path and verify the
  correct viewer.
- Recheck Ghost and Presence inactive-tab behavior without allowing discarded,
  frozen, closed, signed-out, or sleeping tabs to claim progress.

No authenticated mutation is claimed by this record. Current Instagram markup
can change independently of fixture coverage.

# 4.2.0 acceptance

## Source and automated coverage

The starting 4.1.6 tree passed assembly and 1,044 tests. The 4.2.0 tree passes
assembly and **1,054 tests**. The additions cover:

- Continuous Presence beyond the former five-action burst and 200-action default; optional breaks, elapsed expiry, Pause, Stop and restriction handling.
- Start Ghost Mode through discovery, exact inventory confirmation and the existing single-tab / managed-tab runners.
- Bounded opening retries, fresh launch identities, account-change interruption, and no restart of an active worker with a lost heartbeat.
- Loaded-post deduplication, Unicode hashtag links, unknown dates/media, UTC aggregation, explicit partial coverage and inert downloads.

Local Windows validation passed:

- Complete extension/generated-userscript browser acceptance, including short direct/group chats, reels, native replies, retained virtual rows, uncertainty, Stop and owned-reaction removal.
- Ghost primary-button discovery and confirmation; three conversations handled by two reusable renderer windows, with delayed page mounts and real Web Locks. The userscript-manager transport and Instagram pages were simulated.
- Twelve Presence/insights browser gates, including six consecutive verified Likes beyond the former five-action burst, Stop, native story progression and comment-date exclusion.
- Five rendered Ghost states and five Presence states, including dark/light, narrow, short and true Chromium 200% zoom.
- Forty-five existing overlay states and eleven PWA screenshots, without changing pixel tolerances. The PWA images are byte-identical to the existing local baselines; original capture provenance is retained.
- Real Chrome extension/PWA pairing, generated-bundle parity, dependency audit, repository hygiene and whitespace checks.

The release CI additionally runs the full suite, generated-userscript fixtures, real
multi-window Ghost simulation, responsive layouts, true 200% zoom, overlay/PWA
visual gates, Chrome pairing, packaging and checksums. Exact successful CI
artifacts are promoted without rebuilding.

## Authenticated evidence

The existing signed-in Chrome session was inspected read-only. Its installed
4.1.6 UI showed the mandatory burst/rest controls that this version replaces.

cleanup, complete follower-record recovery, or human screen-reader walkthrough
is claimed from synthetic fixtures. Native Instagram layouts and server
restrictions can still change independently of a release.

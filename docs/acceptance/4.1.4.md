# 4.1.4 acceptance

This record keeps source tests, generated-browser fixtures, and authenticated
Instagram behavior separate. The stable Tampermonkey link changes only after a
release is published.

## DM Unsend repair

- A confirmed Unsend may leave Instagram's virtual message group mounted or
  recycle that group for another payload. The runner now verifies the exact
  payload and surrounding native message anchors instead of requiring the
  container itself to disappear.
- If the exact unchanged message remains after confirmation, the runner retries
  that same message through its native menu. Five unsuccessful attempts end as
  an error with no false removal count.
- If Instagram replaces the row so the outcome cannot be proved, ordinary
  single-conversation cleanup records the unresolved outcome and checks the
  remaining messages. The final state still requires attention; it is not
  presented as a clean success.
- Ghost workers retain their stricter uncertainty stop because cross-tab task
  reassignment cannot safely assume what happened to an external mutation.
- Received messages, changed previews, loading states, optimistic changes that
  revert, and unrelated right-aligned controls remain rejected as proof.
- Voice-note waveform, playback, duration, and slider semantics are now part of
  the retained payload signature. Instagram may keep the outer message group
  and its action control mounted after Unsend; removing the exact audio payload
  no longer looks like an unchanged message.

## Presence repair

- Instagram can expose its Home navigation item as combined icon and caption
  text such as `HomeHome`, while the nested accessible name remains `Home`.
- Presence now considers exact accessible names from the control and its
  descendants. It clicks the observed Home control before looking for a feed
  action and does not manufacture a destination when that control is absent.
- Presence retains the already verified account identity when Instagram hides
  account navigation during a same-tab story or full-screen route. A visible
  different account or any restriction still stops the session.
- Target searches count as an active Presence phase, so the toolbox no longer
  falls back to “Nothing to work on here” while a reviewed routine is moving
  between surfaces.

Automated fixtures do not change Instagram account data and do not establish
current authenticated Instagram compatibility.

## Authenticated gates

- Install the exact 4.1.4 userscript in the intended persistent profile.
- In one approved disposable conversation, prove that multiple sent messages
  are removed without ending after the first retained or recycled native row.
- Prove that a blocked or unavailable peer label does not change sent-message
  ownership checks.
- Start one reviewed Presence session from a DM view and verify that it reaches
  the Home feed before the first enabled activity search.
- Recheck changed-thread, restriction, Stop, inactive-tab, and unresolved-result
  behavior separately.

Any Like, Follow, reaction, or Unsend mutation still requires exact
action-time authorization and a verified result. Current Instagram markup can
change independently of fixture coverage.

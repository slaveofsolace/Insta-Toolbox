# 4.2.1 acceptance

## Changes under test

Inbox discovery starts at the top, preserves the desktop rail and recognizes the
native selected row. Presence waits for feed content after Home navigation,
recognizes `/reels/` permalinks and backs off empty activities independently.
Ghost reviews preserve per-conversation message choices. The optional reaction
count is bound to the same confirmation as the message run.
Grouped reaction badges resolve the selected individual emoji, including flags,
keycaps and skin-tone variants.

## Automated checks

The starting 4.2.0 tree passed assembly and 1,054 tests. The candidate passes
assembly and 1,064 tests, including 94 focused inbox/Presence tests and 54
reaction adapter/pass tests.

- Generated inbox review: five behavioral gates, five rendered states and two
  synthetic verified removals through the shared runner.
- Managed Ghost workers: three synthetic conversations, two reusable windows,
  delayed mounts, real Web Locks, verified removals and received-message retention.
- Generated reaction flow: cancel performs no mutation; the confirmed one-reaction
  pass preserves the received message, closes the dialog and records one removal.
- Generated Presence session: 12 gates and five rendered states.
- Overlay: all 45 screenshot states pass.
- PWA: all 11 screenshot states pass.
- Chrome: real extension/PWA pairing and installability pass.
- Dependency audit: no vulnerabilities reported.

The full cross-platform browser/package matrix and authenticated candidate
tests remain pending. The first CI run exposed an outdated inbox-return-count
assertion; the corrected fixture verifies discovery retains the mounted rail
while execution still re-enters each reviewed conversation.
Visual thresholds and existing baseline images are unchanged.

## Native inspection

The initial connected Chrome installation reported 4.1.6. Read-only inbox discovery
stopped after six conversations with a conversation-change error. The desktop
rail remained mounted. Its selected conversation exposes `aria-pressed=true`.
The Home route appeared before feed articles mounted. Feed links include
`/reels/` as well as `/p/` and `/reel/`.

The current Reactions dialog exposes a separate **Select to remove** subtitle
for an own reaction. Its structure matches the ownership predicate. Native
removal through the candidate and managed worker acceptance remain pending.
Chrome subsequently reported 4.2.0; this is not candidate installation evidence.

Fixture results do not establish current authenticated Instagram compatibility,
whole-inbox completeness, Firefox/Safari support or human screen-reader acceptance.
No private account identifiers or message content are stored in this record.

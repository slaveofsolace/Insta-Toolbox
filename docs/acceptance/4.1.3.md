# 4.1.3 acceptance

This record separates source tests, generated-browser fixtures, and current
authenticated Instagram behavior. The stable Tampermonkey channel changes only
when the release is published.

## DM Unsend traversal

- Whole-conversation cleanup resumes from the browser's current virtual window
  after each verified removal instead of returning to the newest message.
- Finite **Newest** and **Oldest** scopes still re-enter from their reviewed
  edge. A replaced scroller also starts from the appropriate edge.
- Recycled rows remain protected by logical message keys and postcondition
  fingerprints.
- When traversal reaches the oldest edge, it waits for delayed history,
  reacquires a replaced scroller, and requires a stable oldest-boundary proof
  before reporting exhaustion.
- Exact sent-message ownership, exact-thread authorization, one confirmed
  native Unsend control, removal settlement, Stop, expiry, and restriction
  handling are unchanged.
- Ghost uses the same runner and receives the same traversal repair.

## Presence startup

- A Live like me session visibly searches each enabled activity as soon as it
  starts.
- If no target is currently available, Presence makes two short bounded retries
  before entering the reviewed quiet window.
- Only verified actions count toward a burst. Skipped targets cannot cause an
  extra rest.
- Current Instagram story-tray and post role-button matching from 4.1.2 remains
  in place. Each target and result is revalidated before it is logged.

## Automated evidence

- The complete repository suite passes 1005/1005 tests.
- Focused tests cover startup-before-rest ordering, empty startup retries,
  skipped actions within a burst, continuous whole-conversation traversal,
  finite-scope edge restoration, delayed oldest-history loading, normal and
  reversed layouts, and scroller replacement.
- Generated userscript parity, extension and userscript acceptance, Chrome
  pairing, browser QA, overlay and PWA visual checks, dependency audit,
  repository hygiene, package lanes, checksums, and publication scan must pass
  at the exact promoted commit.
- Automated fixtures do not change Instagram account data.

## Authenticated gates

- Install the exact 4.1.3 userscript in the intended persistent profile.
- Confirm that Live like me shows an active search before its first rest and
  performs only an explicitly reviewed activity.
- Unsend disposable sent messages across more than one virtual window and
  verify that the runner reaches the oldest loaded message without repeatedly
  returning to the newest edge.
- Recheck changed-account, changed-thread, restriction, Stop, inactive-tab, and
  uncertain-result behavior separately.
- Any Like, Follow, reaction, or Unsend mutation requires its exact action-time
  authorization and verified result.

Current Instagram markup can change independently of fixture coverage. Do not
claim an authenticated mutation from automated evidence alone.

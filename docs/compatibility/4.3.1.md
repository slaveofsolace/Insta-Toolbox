# Insta Toolbox 4.3.1 compatibility

Tampermonkey remains the primary in-page surface. Local data and release-based
updates are preserved; no new userscript permissions are added.

| Tool | Supported behavior | Limit |
| --- | --- | --- |
| Ghost Mode | Recover redirected inbox workers, open assigned chats, run and close ten-tab groups | Inbox discovery may be partial; native batch removal remains unverified for this patch. |
| DM Unsend | Streaming all/newest/oldest cleanup through the shared runner | Only proven sent messages qualify; unknown outcomes are reported separately. |
| Own reactions | Follow-up or separate reaction pass | Requires supported native own-reaction controls. |
| Presence | Native activities, sessions, activity log and reviewed growth candidates | Later Unfollow requires another review; no browser-closed operation. |
| Mutual Checker | Browse and download complete or partial comparisons | Missing records are unknown, not confirmed non-mutuals. |
| Insights | Reports from loaded profile/post data | Samples, not complete account histories. |
| Desktop/PWA | Local imports, comparisons and ledgers | Not authenticated Instagram worker runtimes. |

Managed workers require userscript-manager tab/storage APIs and Web Locks.
Account pacing is shared across tabs. Suspension, sleep, session expiry and
restrictions interrupt jobs. See [acceptance](../acceptance/4.3.1.md).

# Insta Toolbox 4.1.0 compatibility

Status: development candidate, not published.

| Capability | Tampermonkey userscript | Chrome extension | Desktop / PWA |
| --- | --- | --- | --- |
| Mutual Checker | Existing engine preserved | Existing engine preserved | Imports, review, history, and exports preserved |
| Single-conversation DM Unsend | Restored traversal; complete fixture matrix passed; authenticated 4.1.0 acceptance pending | Existing engine and fixture coverage preserved | No authenticated Instagram worker runtime |
| Ghost cleanup | Reviewed one-to-five managed tabs; serialized account mutations; fixture and rendered acceptance passed | Coordinator foundations only; no connected native worker UI | Unsupported |
| Own-reaction cleanup | Enabled; generated-browser acceptance passed; authenticated acceptance pending | Disabled | Unsupported |
| Presence | Session and finite Live like me modes, native-control adapters, inline log, and separate log window | Not added in 4.1.0 | Unsupported |
| Loaded inactive-tab operation | Ghost workers supported by design; authenticated lifecycle acceptance pending | Managed worker foundations remain gated | Unsupported |

An inactive loaded tab is not the same as a frozen, discarded, closed, signed-out,
or sleeping tab. Browser-closed and computer-sleep operation are unsupported.
Neither Ghost nor Presence bypasses Instagram restrictions or restores action
authority after a reload.

See [acceptance](../acceptance/4.1.0.md),
[reaction cleanup](../REACTION_CLEANUP_4.0.md), and
[inbox cleanup](../INBOX_CLEANUP_4.0.md) for the exact evidence and boundaries.

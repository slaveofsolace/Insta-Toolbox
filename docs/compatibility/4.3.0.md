# Insta Toolbox 4.3.0 compatibility

Tampermonkey remains the primary in-page surface. Existing local data and
release-based updates are preserved.

| Tool | Supported behavior | Limit |
| --- | --- | --- |
| Ghost Mode | Discover available conversations; run ten-tab groups; close before the next group | Discovery may be partial. Tabs stay loaded; mutations share account pacing. |
| DM Unsend | Streaming all/newest/oldest cleanup in the open conversation | Only proven sent messages qualify. Unknown outcomes are not successes. |
| Own reactions | Optional follow-up or separate reaction pass | Native own-reaction controls required; corrected live compatibility unverified. |
| Presence | Native activities, continuous sessions, activity log and reviewed growth candidates | Later Unfollow requires a new review; no unattended browser-closed growth. |
| Mutual Checker | Browse and download complete or partial comparisons | Missing records remain unknown. |
| Insights | Reports from loaded profile/post data | Samples, not complete account histories. |
| Desktop/PWA | Local imports, plans, comparisons and ledgers | Not authenticated Instagram worker runtimes. |

Managed Ghost tabs require supported userscript-manager tab/storage APIs and
Web Locks. Browser suspension, sleep, session expiry and restrictions cannot be
bypassed. See [acceptance](../acceptance/4.3.0.md).

See [acceptance](../acceptance/4.1.6.md) for exact evidence boundaries. Automated fixtures do not establish current Firefox/Tampermonkey compatibility, live Unsend/reaction success or complete inbox discovery. Closed, frozen, discarded, signed-out and sleeping pages cannot continue native UI work.

The reference collectors reviewed for partial lists use server cursors or currently mounted DOM rows. None establishes that Instagram returns every account. This release fixes a duplicate-record parser defect; it does not spoof account age, bypass restrictions or describe missing records as confirmed non-mutuals.

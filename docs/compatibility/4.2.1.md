# Insta Toolbox 4.2.1 compatibility

The userscript remains the primary surface. Existing settings, data and stable
release-based updates are preserved; no new permissions or services are added.

| Tool | Behavior | Limit |
| --- | --- | --- |
| Presence | Uses native navigation and waits for loaded feed controls; available activities continue while empty ones back off | Instagram restrictions, expiry and Stop still end the run. |
| Ghost Mode | Finds available conversations and opens the reviewed worker tabs; Message options apply to each conversation | Tabs prepare together; removals are account-paced. Discovery can remain partial. |
| DM Unsend | Uses the existing streaming runner and verifies each removal | Unknown outcomes remain separate from verified removals. |
| Own reactions | Optional second pass with an optional count; blank means all | Only native own-reaction controls qualify. The count applies to the single-conversation pass. |
| Mutual Checker | Partial comparisons remain visible and downloadable | Missing records are unknown, not confirmed non-mutuals. |
| Insights | Reads loaded post/profile information and exports reports | Loaded-page samples are not full account histories. |

Worker tabs must remain loaded. Browser shutdown, sleep, frozen/discarded tabs,
lost session evidence and restrictions cannot be bypassed by background mode.
Desktop and PWA remain local workspaces, not authenticated Instagram controllers.

See [acceptance](../acceptance/4.2.1.md) for the current verification status.

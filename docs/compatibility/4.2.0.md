# Insta Toolbox 4.2.0 compatibility

The Tampermonkey userscript is the primary surface for these additions. The
existing extension, desktop and web packages remain available without a new
remote service or permission expansion.

| Feature | Behavior | Limit |
| --- | --- | --- |
| Presence | Runs selected activities continuously until Stop or the selected duration | Normal action spacing and Instagram restriction checks remain. Optional scheduled breaks start off. |
| Ghost Mode | Discovers available chats, confirms exact thread IDs, opens 1–5 managed tabs and runs the existing Unsend engine | Tabs prepare in parallel; account-level mutations are serialized. Only job-created tabs are closed. |
| Unsend | Streams loaded history, handles virtual rows and short chats, retries unchanged targets | Only proven removals count. Unresolved rows are reported, never called deleted. |
| Insights | Reads loaded posts and visible profile counters; exports text/JSON | A page sample, not whole-account history. Linked hashtags may come from captions or comments. |
| Mutual Checker | Accumulates returned pages and retains partial results | Profile totals do not prove that Instagram exposes every record. Missing accounts remain unknown. |

Background tabs must remain loaded. Frozen/discarded/closed tabs, lost account
evidence, browser shutdown and computer sleep cannot continue native page work.
An opening timeout can retry twice before any worker claims the conversation.
A lost active worker is not replaced automatically.

No local-model runtime is bundled. The audited Osintgram implementation uses
Ollama in addition to a separate Instagram data backend; its model does not
unlock missing follower records. See [source audit](../SOURCE_AUDIT_4.2.0.md).

Version 4.2.0 preserves existing settings and history. The additive
`scheduledBreaks` preference defaults to false, including older saved live-mode
preferences. Existing burst/rest values remain available when breaks are enabled.

See [acceptance](../acceptance/4.2.0.md) for fixture and authenticated evidence.

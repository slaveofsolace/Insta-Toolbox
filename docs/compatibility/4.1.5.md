# Insta Toolbox 4.1.5 compatibility

| Capability | Tampermonkey | Chrome extension | Desktop / PWA |
| --- | --- | --- | --- |
| Mutual Checker | Existing engine, partial results and exports preserved | Preserved | Imports, comparison history and exports preserved |
| DM Unsend | Streaming All mode, ordered finite selections, waveform-only voice rows, bounded retries and separate unresolved accounting | Shared runner and fixtures | No authenticated Instagram runtime |
| Ghost cleanup | Reviewed one-to-five worker pool; serialized removals; delayed mounts, persistent inbox rail and tab reuse covered | Coordinator foundations only | Unsupported |
| Own-reaction cleanup | Existing adapter and generated-browser coverage preserved | Disabled | Unsupported |
| Presence | ID-less stories, native activity transitions, immediate startup, finite/Live like me sessions and updating local log | Not included | Unsupported |
| Loaded inactive tabs | Requires an open, usable Instagram page; no forced focus | Existing background boundaries | Unsupported |

The two-worker generated-browser test uses synthetic pages and a GM API shim.
It does not prove current authenticated Tampermonkey or Firefox compatibility.
Account-facing mutations have not been validated for this patch. See the
[acceptance record](../acceptance/4.1.5.md).

Frozen, discarded, closed, signed-out or sleeping pages cannot continue native
UI work. Progress may survive; expired action authority does not. Shared
restrictions still apply across workers. Inbox discovery can be partial, and
cleanup reports completed, failed and unresolved outcomes rather than claiming
that inaccessible history was erased.

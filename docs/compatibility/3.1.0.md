# Insta Toolbox 3.1.0 compatibility

## Supported surfaces

| Surface | Release target |
| --- | --- |
| Tampermonkey | Current Chrome or Chromium with Allow User Scripts enabled |
| Chrome extension | Current Chrome, loaded unpacked from the release ZIP |
| Web/PWA | Current Chromium at the GitHub Pages URL or a secure self-hosted origin |
| Windows | Unsigned x64 installer |
| macOS | Universal ad-hoc-signed DMG and ZIP; not notarized |

## Upgrade behavior

Tampermonkey updates version 3.0 to 3.1 through the same stable release URL. Existing version 3 settings and local data remain in place. The new launcher position and visual choices are additive. Version 2 data remains separate and is not migrated or deleted.

## Instagram boundary

Instagram can change its interface without notice. Account-free fixtures verify selectors and safety behavior against controlled pages. Record any current authenticated check in [the 3.1 acceptance record](../acceptance/3.1.0.md) without storing private account data.

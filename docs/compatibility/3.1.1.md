# Insta Toolbox 3.1.1 compatibility

## Supported surfaces

| Surface | Release target |
| --- | --- |
| Tampermonkey | Current Chrome or Chromium with **Allow User Scripts** enabled |
| Chrome extension | Current Chrome, loaded unpacked from the release ZIP |
| Web/PWA | Current Chromium at the GitHub Pages URL or a secure self-hosted origin |
| Windows | Unsigned x64 installer |
| macOS | Universal ad-hoc-signed DMG and ZIP; not notarized |

## Update behavior

Tampermonkey updates version 3 through the same stable release URL. Version 3 settings and local data remain in place. Version 2 data stays separate and is not migrated or deleted.

Version 3.1.1 claims the page before asynchronous startup. If two current userscript copies are enabled, only one toolbox mounts. The Chrome extension still takes precedence when both delivery surfaces are present. Removing unused copies is recommended so update behavior stays obvious.

## Instagram boundary

Instagram can change its interface without notice. Account-free fixtures verify selectors and safety behavior against controlled pages. Current authenticated checks belong in [the 3.1.1 acceptance record](../acceptance/3.1.1.md) without private account data.

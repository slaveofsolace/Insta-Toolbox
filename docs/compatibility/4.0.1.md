Status: development candidate, not published.

| Capability | Userscript | Chrome extension | Desktop / PWA |
| --- | --- | --- | --- |
| Mutual Checker and reviewed Follow / Unfollow | Existing engine preserved | Existing engine preserved | Imports, review, pairing, and exports preserved |
| Single-conversation DM Unsend | Full fixture matrix passed | Full fixture matrix passed | No authenticated Instagram worker runtime |
| Reviewed inbox cleanup | Serial userscript flow passed in fixtures | Coordinator modules tested; native execution not connected | Unsupported |
| Own-reaction cleanup | Adapter and flow tested; authenticated acceptance pending | Disabled pending the same gate | Unsupported |
| Presence | Five-action userscript session passed production-shaped fixtures | Not added to the extension in this candidate | Unsupported |
| Background execution | Inactive loaded tab is the intended boundary; lifecycle acceptance pending | Managed worker modules remain gated | Unsupported |

Presence supports story views, story reactions, post likes, follows, and request
acceptance through exact rendered controls. Its review is finite, account-bound,
runtime-only, and expires within 15 minutes. It stops on changed context,
restrictions, or an uncertain result.

The current evidence is synthetic and production-shaped. It does not prove the
latest authenticated Instagram layouts, reliable discovery beyond rendered
targets, operation after the tab closes, or shared cross-tab ownership with an
active Ghost run.

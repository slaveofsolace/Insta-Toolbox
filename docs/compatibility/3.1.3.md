# Insta Toolbox 3.1.3 compatibility

## Supported surfaces

| Surface | Release target |
| --- | --- |
| Tampermonkey | Current Chrome or Chromium with **Allow User Scripts** enabled |
| Chrome extension | Current Chrome, loaded unpacked from the release ZIP |
| Web/PWA | Current Chromium at the GitHub Pages URL or a secure self-hosted origin |
| Windows | Unsigned x64 installer |
| macOS | Universal ad-hoc-signed DMG and ZIP; not notarized |

## Update behavior

Tampermonkey updates version 3 through the stable release URL. Version 3
settings and local data remain in place. Version 2 data stays separate and is
not migrated or deleted.

## Mutual Checker behavior

The checker performs one bounded, same-origin cursor traversal for Followers
and one for Following. It uses Instagram's current follow-list request shape,
deduplicates stable account identities, and compares the returned rows locally.

A list is complete only when the returned unique identities exactly match the
verified profile total and Instagram has finished pagination. If Instagram
limits the list, omits a next cursor, changes the profile total, or returns
conflicting state, the visible result remains partial. Partial rows can be
reviewed and exported, but cannot become Follow / Unfollow targets.

Instagram's private web relationship route is not a supported public API and
can change without notice. Even a valid cursor walk may omit unavailable,
restricted, or platform-limited identities. The toolbox reports that boundary
instead of rerunning the entire list or guessing missing accounts.

## Instagram boundary

Account-free fixtures verify pagination, request shape, platform-limit flags,
missing cursors, retries, and safety behavior against controlled responses.
Current authenticated results belong in
[the 3.1.3 acceptance record](../acceptance/3.1.3.md) without private account
data.

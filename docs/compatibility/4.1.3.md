# Insta Toolbox 4.1.3 compatibility

Status: release candidate.

| Capability | Tampermonkey userscript | Chrome extension | Desktop / PWA |
| --- | --- | --- | --- |
| Mutual Checker | Existing engine and partial-result behavior preserved | Existing engine preserved | Imports, review, history, and exports preserved |
| Single-conversation DM Unsend | Continuous virtual-window traversal, delayed oldest-history settling, and retained-slot removal proof covered by fixtures; authenticated 4.1.3 acceptance pending | Shared runner and fixture coverage preserved | No authenticated Instagram worker runtime |
| Ghost cleanup | Reviewed one-to-five managed tabs; serialized account mutations; uses the repaired Unsend traversal and verification | Coordinator foundations only; no connected native worker UI | Unsupported |
| Own-reaction cleanup | Existing generated-browser acceptance preserved; authenticated acceptance pending | Disabled | Unsupported |
| Presence | Starts with an active search cycle, retries briefly before rest, recognizes current story-tray and post role buttons, and retains finite sessions plus the local log | Not included | Unsupported |
| Loaded inactive-tab operation | Supported only while the Instagram worker remains loaded and usable; authenticated lifecycle acceptance pending | Managed worker foundations remain gated | Unsupported |

An inactive loaded tab is not the same as a frozen, discarded, closed,
signed-out, sleeping, or browser-closed tab. Neither Ghost nor Presence bypasses
Instagram restrictions or restores action authority after a reload.

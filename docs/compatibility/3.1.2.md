# Insta Toolbox 3.1.2 compatibility

## Supported surfaces

| Surface | Release target |
| --- | --- |
| Tampermonkey | Current Chrome or Chromium with **Allow User Scripts** enabled |
| Chrome extension | Current Chrome, loaded unpacked from the release ZIP |
| Web/PWA | Current Chromium at the GitHub Pages URL or a secure self-hosted origin |
| Windows | Unsigned x64 installer |
| macOS | Universal ad-hoc-signed DMG and ZIP; not notarized |

## Update behavior

Tampermonkey updates version 3 through the same stable release URL. Version 3
settings and local data remain in place. Version 2 data stays separate and is
not migrated or deleted.

## Mutual Checker behavior

The checker uses bounded same-origin Instagram reads, isolates each pagination
pass, and retries early list endings without combining changing memberships.
The toolbox shows all locally captured comparison groups in progressive
25-row batches and keeps both the readable text report and schema-1 JSON
download.

When Instagram does not expose enough rows to match a verified account count,
the saved result remains partial. Partial rows can be reviewed and exported,
but they cannot become Follow / Unfollow targets.

## Instagram boundary

Instagram can change its interface without notice. Account-free fixtures
verify selectors and safety behavior against controlled pages. Current
authenticated checks belong in [the 3.1.2 acceptance record](../acceptance/3.1.2.md)
without private account data.

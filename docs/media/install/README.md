# Install guide captures

The install guide uses cropped browser captures rather than illustrated controls.

The red pointer is adapted from [Red Arrow Up.png](https://commons.wikimedia.org/wiki/File:Red_Arrow_Up.png) by Bigmorr. The source was released into the public domain. The downloaded PNG SHA-256 was `606af5d968fe8fd841a8ea6e00bc572eb9f64f392c3c47f828c098867caebeaa`; only rotation, scaling, transparency, and placement were changed.

| File | Source |
| --- | --- |
| `01-allow-user-scripts.png` | Tampermonkey 5.5.0 extension details in Chromium, with an arrow on the **Allow User Scripts** switch. |
| `02-install-userscript.png` | Tampermonkey 5.5.0 rendering Insta Toolbox 3.1.0, cropped to the script details with an arrow on the left-side **Install** button. |
| `03-open-toolbox.png` | The tracked 3.1.0 collapsed-launcher browser QA capture, cropped to the **IT** button. |

The committed crops contain no account names, messages, bookmarks, profile details, cookies, or session data.
